# ADR-009: 데이터 프라이버시 (P3-2)

## 상태
채택 (2026-06-13)

## 배경
"고객의 광고 카피·계약서가 절대 유출되지 않는다"는 본 제품의 3대 핵심 가치 중 하나(Data Privacy)이자 보안 마케팅의 근거다. ROADMAP P3-2는 세 가지를 요구한다: ① LLM 학습 거부 ② 입력 마스킹 ③ 분석 이력 AES-256 암호화.

## 결정

### 1. 분석 이력 AES-256-GCM 암호화 (핵심)
`audit_history`의 `ad_copy`, `report_json`을 **AES-256-GCM**으로 암호화 저장한다.

- **GCM 선택**: 기밀성 + 무결성(인증 태그)을 함께 제공. CBC 대비 변조 탐지 가능 — [[해시 MAC 디지털 서명]] 관점에서 AEAD가 정답.
- **투명 암호화**: JPA `AttributeConverter`(`EncryptedStringConverter`)를 필드에 `@Convert`로 부착 → 저장 시 자동 암호화, 조회 시 자동 복호화. 도메인 코드는 평문만 다룬다.
- **저장 포맷**: `enc1:` + base64(IV‖ciphertext‖tag). IV는 매 암호화마다 12바이트 랜덤(GCM nonce 재사용 금지).
- **레거시 호환**: `enc1:` prefix 없으면 평문(P3-3 시기 데이터)으로 간주해 그대로 반환 → 마이그레이션 없이 점진 전환.
- **키 관리**: `APP_AES_KEY`(base64 32바이트) 환경변수 주입. 로컬 기본값은 개발 전용. 운영 키는 시크릿 매니저. 키 분실 = 복호화 불가이므로 키 백업은 운영 절차로.

### 2. 로그·전송 마스킹
- **로그**: 광고 카피 원문을 로그에 남기지 않는다(이미 P3-3에서 `copyLength`만 로깅). 에러 로그에도 원문 금지.
- **PII 마스킹 유틸**(`PiiMasker`): 이메일·전화번호·주민등록번호 패턴을 마스킹. 적용 지점은 로그/디스플레이(저장은 암호화라 원문 보존). 광고 카피는 분석 대상이라 LLM 전송 시엔 원문 유지.

### 3. LLM 학습 거부 — 무료 티어의 한계 명문화
- **현실**: Gemini 무료 티어는 입력이 모델 학습에 사용될 수 있고, 학습 거부 옵션이 없다(ADR-006 §트레이드오프).
- **정책**: `agent.llm.data-collection-opt-out` 설정 자리를 마련하되, 무료 티어에서는 코드로 강제 불가 → **"무료 티어 운영 = 실고객 데이터 금지"를 OPERATIONS에 명문화**. 베타는 테스트/공개 데이터만.
- **유료 전환 트리거**: 실고객 데이터를 받는 시점 = 유료 모델(학습 미사용) 전환 시점. 이때 opt-out 플래그를 true로. 암호화는 이미 적용돼 있어 저장 측 보호는 무료 기간에도 유지.

## 트레이드오프 / 리스크
- **암호화된 컬럼은 검색·인덱싱 불가** — `report_json`을 DB에서 쿼리할 수 없다. 사용량 카운팅은 `created_at`만 쓰므로 무관. 향후 이력 검색이 필요하면 별도 메타 컬럼(평문 비민감)으로.
- **키 분실 = 데이터 영구 손실** — 운영 키 백업 필수.
- **무료 티어 학습 거부 불가** — 저장은 암호화하지만 LLM 전송분은 무료 기간 학습될 수 있음. 실고객 금지 정책으로만 방어. 이건 P3-2가 완전히 해결 못 하는 잔여 리스크이며, 유료 전환으로만 종결된다.

## 검증 기준
- `EncryptionService` 단위: round-trip, 다른 키로 복호화 실패, GCM 변조(태그) 탐지, IV 매번 상이.
- `PiiMasker` 단위: 이메일·전화·주민번호 마스킹.
- 실 DB E2E: 분석 1건 저장 후 **DB 원시 조회 시 `enc1:` 암호문**(평문 카피 노출 안 됨), 앱 조회 시 복호 평문.
