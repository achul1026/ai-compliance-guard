# ADR-006: LLM 엔진 선택 (D5) — 무료 티어 우선

## 상태
채택 (2026-06-13) — 사용자 승인 완료

## 전제 (이 결정을 지배하는 제약)

1. **수익 발생 전까지 비용 ≈ 0** (사용자 확정 원칙)
2. **개발 머신 = Intel i5 Mac, GPU 없음** → 로컬 LLM(Ollama 등)은 14B급에서 1~3 tok/s로 3-에이전트 루프에 사용 불가. 로컬 추론 탈락.
3. 결론: **무료 티어 클라우드 API**가 유일한 경로. 단, `LlmPort` 인터페이스로 격리해 수익화 후 유료 전환 비용을 최소화한다.

ROADMAP 원안의 후보(GPT-4o vs Upstage Solar)는 둘 다 유료라 전제 1에서 탈락. 비교 대상을 무료 티어로 재구성했다.

## 후보 비교

| 축 | Gemini Flash (Google AI) | Groq (Llama 3.3 70B 등) | OpenRouter `:free` | Upstage 무료 크레딧 |
|---|---|---|---|---|
| 무료 한도 | **10 RPM / 1,500 RPD / 250K TPM** | 모델별 상이 (~30 RPM급) | 크레딧 없으면 ~50 req/일 | 소액 크레딧, 소진 시 종료 |
| 한국어 품질 | **상** (법률 추론 무난) | 중 (Llama 한국어 약함) | 모델 따라 들쭉날쭉 | 상 (한국어 특화) |
| JSON 구조화 출력 | **네이티브 지원** (responseSchema) | 지원 | 모델별 상이 | 지원 |
| LangChain4j 모듈 | **공식** (`langchain4j-google-ai-gemini`) | OpenAI 호환으로 가능 | OpenAI 호환 | OpenAI 호환 |
| 지속 가능성 | 안정적 (Google 정책상 무료 티어 유지) | 한도 변동 잦음 | 불안정 | 크레딧 소진 = 끝 |
| 유료 전환 시 단가 | Flash 계열 매우 저렴 | 저렴 | 다양 | 중간 |

## 결정 (제안)

**1차: Google Gemini Flash 무료 티어. `LlmPort` 인터페이스 + provider 토글(`agent.llm.provider=gemini|mock`)로 격리.**

- 검사관·비판관·교정관 3-에이전트 × 순환 루프 1~2회 = 분석 1건당 LLM 호출 ~5회 → 1,500 RPD로 **일 ~300건 분석 가능**. 개발 + 초기 베타에 충분.
- 테스트·CI는 `mock` provider로 호출 0건 (기존 BGE-m3 전환과 동일한 패턴 — ADR-005의 `embedding.provider` 토글과 정합).
- Groq를 2순위 폴백으로 명시 (Gemini 한도 소진 시 수동 전환).

## ⚠️ 알려진 트레이드오프 (정직하게)

1. **무료 티어 데이터 학습 사용**: Google 무료 티어는 입력이 모델 개선에 사용될 수 있다. 본 프로젝트 핵심 가치 "Data Privacy(고객 카피 비유출)"와 충돌.
   - **개발·베타(공개 규정 + 테스트 카피)**: 문제 없음.
   - **실고객 카피를 받는 시점**: 유료 티어 전환 필수 (유료는 학습 미사용). Flash 단가가 매우 낮아 분석 1건당 원가 ~1~5원 수준 → 건당 과금 모델에서 흡수 가능. **이것이 "수익 발생 시점 = 유료 전환 시점"의 자연스러운 트리거.**
2. **GPT-4o 대비 추론 품질**: Flash는 최상위 모델이 아니다. 비판관(Critique)의 교차 검증 루프가 품질 보완 장치 역할 — 본 아키텍처가 이미 이를 전제로 설계됨.
3. RPD 1,500은 출시 후 성장 시 병목 → 그때는 수익이 있으므로 유료 전환.

## 검증 기준
- P2-1에서 Gemini 호출 1회가 엔드투엔드 동작 (광고 카피 → 위반 분석 JSON 응답)
- mock provider로 `./gradlew test` 시 외부 호출 0건
